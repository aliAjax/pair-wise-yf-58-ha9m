# pair-wise-yf-58 功能开关和灰度发布控制台

## 源提示词摘要
产品负责人配置目标用户、地区、应用版本和依赖条件，研发负责人审批发布计划，值班人员观察过程并随时关闭开关。系统支持规则组合、流量逐步增加、定时生效、紧急停止、回滚，并能在保存前模拟不同用户的命中版本。

## 技术栈
Vue 3 + TypeScript + Vite + Ant Design Vue + Pinia + Vue Router + Axios + VueUse + VeeValidate + Zod + Vue I18n。

## 已实现闭环
- 功能开关、发布计划、审计记录三类业务对象。
- 规则组合、原有的规则模拟与定时、审批、应急操作等核心功能均已支持，同时配套离线提示、输入校验与本地持久化能力。

## 发布快照编号闭环
- **旧数据回填**：没有版本编号的旧开关/审批在首次加载时回填为每个开关的 `v1` 初始快照（标记「v1 回填」）。
- **带编号快照**：每次提交生成递增编号快照（`config` 配置类 / `control` 控制类）；模拟、放量、紧急停止、回滚和审计都引用编号，可用任意历史编号对同一个用户**复算**当时结果（灰度桶按用户 ID 稳定哈希，与编号无关）。
- **作废重算**：规则、待审状态下的放量或定时改动后，未发布的待审快照与其上的审批记录一起作废，重新提交生成新编号；已发布快照作为历史保留。
- **双标签页字段合并**：收到另一标签页保存时做三方（base/本页/他页）按字段合并——只有一边改过的字段自动并入；两边都改同一字段则保留本地/远端两份值，逐字段人工确认。
- **写盘失败重试清单**：失败改动携带完整状态片进入清单；重开后可分清 **生效中 / 待审批 / 写盘失败** 三项，支持逐项/全部重试，按 `rev` 幂等重放。

### 演示钩子（页面右上角）
- 「模拟他页保存(自动合并)」「模拟两页同改(冲突)」：无需真开两个标签页即可演示字段合并。
- 「制造一次写盘失败」：随后任意保存即进入重试清单（真实双标签页通过 `storage` 事件合并）。
